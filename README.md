# Flange & Stud Bolt Finder — فلنج و استادبول یاب

برنامه وب **کاملاً آفلاین** برای مهندسان مکانیک، پایپینگ و مکانیک سیالات صنایع نفت، گاز و پتروشیمی:
جستجوی تعداد/قطر/طول استادبول فلنج‌ها بر اساس **ASME B16.5** و **ASME B16.47 (Series A/B)** و
جستجوی سایز آچار مهره بر اساس **ASME B18.2.2** — با رابط فارسی، راست‌به‌چپ و فونت وزیرمتن.

## روش‌های اجرا و توزیع محلی (Manual Local Distribution)

این برنامه بدون وابستگی خارجی و بدون نیاز به هیچ بیلد یا سکرتی طراحی شده است.

### روش اول: اجرای کامل با سرور محلی و قابلیت نصب PWA (۴ گام ساده)

1. **دانلود یا استخراج پروژه**: آخرین نسخه را از محیط پروژه یا فایل ZIP استخراج کنید.
2. **تولید یک‌بارهٔ دارایی‌های بصری**: در پوشهٔ پروژه دستور زیر را یک‌بار اجرا کنید تا آیکن‌های برنامه به‌صورت محلی ساخته شوند:
   ```bash
   npm run assets
   ```
3. **اجرای سرور صفر-وابستگی**:
   ```bash
   npm start
   # یا: node server.js
   ```
   *(نکته: `npm install` کاملاً اختیاری است و به دلیل صفر بودن وابستگی‌ها نیازی به دانلود پکیج ندارد).*
4. **باز کردن در مرورگر و نصب PWA**:
   آدرس `http://localhost:3000` را در مرورگر (Chrome یا Edge) باز کنید. با کلیک روی آیکون نصب (Install) در نوار آدرس، برنامه به عنوان یک وب‌اپلیکیشن مستقل دسکتاپ نصب می‌شود و حتی در صورت توقف سرور نیز به‌صورت آفلاین از کش اجرا خواهد شد.

### روش دوم: حالت آفلاین بدون سرور (Mode A — دابل‌کلیک)
فایل `index.html` را مستقیماً با دوبار کلیک در مرورگر باز کنید (Chrome / Edge / Firefox). بدون سرور، بدون اینترنت و بدون نصب.

> نکته فنی: در حالت دابل‌کلیک (`file://`)، به دلیل محدودیت‌های امنیتی مرورگر برای `fetch` محلی، برنامه به‌طور خودکار و هوشمند از داده‌های تعبیه‌شده در `data/data-embedded.js` استفاده می‌کند.

## امکانات
- **جستجوی فلنج**: ComboBox جستجودار سایز (NPS/DN — تایپ `6`، `6"`، `DN150`، `150`، `0.5`)،
  کلاس فشاری فیلترشده بر اساس سایز، فیس (RF/RTJ/FF)، نوع گسکت → تعداد استادبول، قطر (اینچ/mm)،
  طول استاندارد جدول، سایز آچار مهره (mm/اینچ)، ضخامت فلنج، رزوه، و **تفکیک محاسبه طول**.
- **جستجوی آچار/Stud**: اینچ یا میلی‌متر (`3/4`، `0.75`، `19`، `19.05`، `M20`) → آچارخور mm/اینچ،
  AF و ارتفاع مهره، مهره سنگین و معمولی (B18.2.2)، سایزهای متریک ISO 4032/4033.
- تاریخچه و علاقه‌مندی‌ها (localStorage)، کپی نتیجه، خروجی CSV، چاپ، تنظیمات محاسبات،
  ورود/خروج JSON، پوسته تاریک/روشن، کلیدهای میان‌بر کیبورد در فهرست‌ها.

## فرمول طول استادبول
```
L = n × t_flange + t_gasket + 2 × h_nut + 2 × p_thread
```
- `n = 2` (دو فلنج)، `t_flange` از جدول استاندارد، `h_nut` از جدول مهره سنگین B18.2.2،
  `p_thread = 6 mm` از هر سر (قابل ویرایش در تنظیمات).
- طول‌های «جدول» استاندارد بر پایه گسکت اسپیرال‌ووند ۴٫۵ mm (فشرده‌شده به ۳ mm) و مهره سنگین هستند؛
  طول جدول **مبنای خرید** است و مقدار محاسبه‌شده فقط برای کنترل/تخمین نمایش داده می‌شود
  (اختلاف هر رکورد در کارت نتیجه نمایش داده می‌شود).

## داده‌ها و درجه اطمینان
- منابع: جداول عمومی B16.5 (بولتینگ RF/RTJ + ضخامت)، جدول کلاس ۴۰۰، جداول B16.47 Series A/B،
  جداول مهره B18.2.2 (دو منبع مستقل که با هم سازگارند) و ISO 4032/4033 برای متریک.
- رکوردهای دارای برچسب «نیازمند بازبینی» (حدود ۲۰ رکورد) و اندازه‌های مهره متریک باید با
  آخرین ویرایش استاندارد کنترل شوند. NPS 22 (DN550) در دیتاست بولتینگ موجود نیست و باید تکمیل شود.
- کلاس ۹۰۰ در B16.47 فقط تا NPS 48 در دیتاست است.

## عیب‌یابی (عناوین سریع)
| نشانه | علت | راه‌حل |
|---|---|---|
| هیچ تب/دکمه‌ای کار نمی‌کند | خرابی یا ناقص بودن یکی از فایل‌های `js/` | کنسول مرورگر (F12) را ببینید؛ برچسب گوشه بالا سمت چپ پیام «خطا: …» را نشان می‌دهد |
| برچسب بالا می‌گوید «خطا در بارگذاری داده‌ها» | فایل‌های `data/*.js` پیدا نشدند | مطمئن شوید پوشه `data` کنار `index.html` است |
| پیام «داده برای این ترکیب … موجود نیست» | ترکیب سایز/کلاس در دیتاست نیست (مثلاً NPS 22) | از تب تنظیمات، JSON تکمیل‌شده را بارگذاری کنید |
| فونت فارسی وزیرمتن نیست | فایل‌های woff2 در پوشه `fonts` نیستند | `fonts/README.txt` را ببینید (برنامه با Tahoma/Arial هم کار می‌کند) |
| خطای آیکن در کنسول مانیفست PWA | آیکن‌های PNG هنوز ساخته نشده‌اند | اجرای دستور `npm run assets` یا `npm run icons` |
| تعداد/قطر استادبول درست است ولی طول جدول خالی | رکورد آن ترکیب در `flange-bolting.json` نیست | ترکیب را با «خروجی بسته داده فعلی» بگیرید، تکمیل و بارگذاری کنید |

### ابزارهای توسعه (تست و نگهداری)
```bash
npm run assets        # تولید دارایی‌های محلی (آیکن‌ها و فونت‌ها)
npm run icons         # تولید آیکن‌های PNG مانیفست
npm run fonts         # دیکود فونت‌های base64 در صورت وجود سورس
npm run data          # ساخت مجدد JSONها از جداول خام + گزارش اعتبارسنجی
npm test              # تست منطق محاسبات و جستجو
npm run lint          # بررسی وجود تمام شناسه‌های DOM در HTML
```

## ویرایش داده‌ها
1. فایل JSON مربوطه را در `data/` با هر ویرایشگر متنی تغییر دهید، **یا**
2. برنامه را باز کنید → تب تنظیمات → «بارگذاری …json» (فایل در localStorage ذخیره می‌شود)،
   سپس «خروجی بسته داده فعلی» برای گرفتن نسخه کامل.
3. برای بازتولید فایل‌ها از جداول خام: `node tools/generate-data.js` (گزارش اعتبارسنجی در `tools/data-report.txt`).
